# SSRIS - Student Supervisor Research Interaction System
## System Presentation

---

### 1. System Overview
**SSRIS** is an online system designed specifically for **Moshi Cooperative University (MOCU)** to manage the research supervision and interaction process for postgraduate students. This system involves multiple users including students, supervisors, and administrators working together efficiently.

---

### 2. Tools and Technologies Used

#### Backend
- **Laravel Framework** v12.x - PHP framework
- **PHP** v8.2.4 - Server-side programming language
- **MySQL** - Database management system

#### Frontend
- **Bootstrap** - CSS framework for responsive design
- **Font Awesome** - Icons library
- **Blade Templates** - Laravel templating engine
- **JavaScript** - Client-side interactivity

#### Development Tools
- **Laragon** - Local development server
- **Composer** - PHP dependency manager
- **Git** - Version control

---

### 3. System Requirements

#### System Requirements
- **Web Server:** Apache/Nginx
- **PHP Version:** 8.2 or higher
- **Database:** MySQL 5.7+ or MariaDB
- **Browser:** Chrome, Firefox, Safari, Edge (modern browsers)

#### Operational Requirements
- **Internet Connection** for downloading and uploading documents
- **Storage Space** for storing research documents
- **Email System** for communication

---

### 4. User Roles

#### 1. Admin (System Administrator)
- Registers new users
- Assigns students to supervisors
- Manages the entire system
- Views system reports and statistics

#### 2. Supervisor (Research Supervisor)
- Views assigned students
- Reviews and provides feedback on research documents
- Conducts meetings with students
- Monitors research progress

#### 3. Student
- Registers and submits research documents
- Views research progress
- Receives feedback from supervisor
- Attends meetings with supervisor

---

### 5. Key Features

#### A. User Registration and Management
- Registration of new users
- Creation of admin, supervisor, and student accounts
- User profile management

#### B. Research Document Management
The system involves three types of documents:
1. **Proposal** - Research plan
2. **Data Collection & Analysis** - Data collection and analysis
3. **Report** - Final research report

#### C. Document Approval Process
- Students can submit documents
- Supervisors review and provide feedback
- Document statuses: Pending, Under Review, Approved, Rejected, Revision Required

#### D. Feedback System
- Supervisors can provide feedback on documents
- Students receive feedback and can make revisions
- Priority levels: Low, Medium, High, Urgent
- Due dates for completing revisions

#### E. Meetings
- Schedule meetings between supervisor and student
- Meeting records and notes
- Meeting types: Regular, Progress Review, Final Defense

#### F. Messaging
- Messaging system between users
- Notifications for new activities
- Tracking of read and unread messages

#### G. Reports and Analytics
- Student statistics by program
- Student statistics by year
- Research progress reports
- Supervisor performance reports

---

### 6. Workflow

1. **Registration:** Admin registers all users
2. **Assignment:** Admin assigns students to supervisors
3. **Proposal Submission:** Student submits proposal
4. **Proposal Review:** Supervisor reviews proposal and provides feedback
5. **Data Collection:** Student submits data collection document
6. **Report Submission:** Student submits final report
7. **Final Approval:** Supervisor approves report
8. **Completion:** Research is completed

---
